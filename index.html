Project 1: E-commerce Order Analysis

Project Description

This project analyzes e-commerce sales performance using Microsoft Excel. The dashboard was built to identify sales trends, customer behavior, and top-performing product categories.

Tools Used

  • Microsoft Excel
  • Pivot Tables
  • Pivot Charts
  • Slicers
  • Timeline Filters

Key Findings

  • Technology products generated the highest revenue.
  • Sales peaked during the fourth quarter.
  • Most orders came from repeat customers.
  • California had the highest number of purchases.
